# Noto Sans

Arquivo de fonte variável autohospedado para a tipografia corporal da aplicação.

| Propriedade | Valor |
| :--- | :--- |
| Família tipográfica | Noto Sans variável |
| Arquivo | `NotoSans-latin-wght.woff2` |
| Formato | WOFF2 |
| Eixo variável | `wght` de 100 a 900 (`wdth` fixado em 100) |
| Recorte | Latin, Latin-1, Latin Extended-A, pontuação geral e os símbolos usados na interface |
| Repositório de origem | [notofonts/latin-greek-cyrillic](https://github.com/notofonts/latin-greek-cyrillic), versão 2.015 |
| Autoria | The Noto Project Authors, Steve Matteson |
| Licença | SIL Open Font License 1.1, descrita nos arquivos `OFL.txt` e `AUTHORS.txt` |
