# K-pop Group Code

Canonical: https://kpopquiz.online/en/code/
Also in Portuguese: https://kpopquiz.online/pt-br/codigo/

Find four different catalog groups in the day's secret order. Pick a group for
each of the 4 positions and submit your guess. You get 10 attempts.

After each attempt, the game shows how many groups are in the exact position
and how many belong to the code but sit elsewhere. The numbers are aggregates
and never say which positions you got right. The code changes at midnight São
Paulo time and is the same for every player that day.

## Provenance and license

The six symbols come from the accepted group catalog, each with its music type
classification on Wikidata (CC0,
https://www.wikidata.org/wiki/Wikidata:Copyright), pointing at the consulted
revision. The sequence is a logic challenge: the game claims no relationship
between the groups that form the code.
